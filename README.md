# Warcraft III Replay Lab

## Запуск

1. Установить Python 3.11 или новее.
2. Выполнить `python -m pip install -r requirements.txt`.
3. Запустить `START_REPLAY_LAB.cmd`.

## Работа с Warcraft

Выбери реплей и нажми `Открыть в Warcraft`. Если установлен iCCup Launcher, приложение само запустит Warcraft через его кнопку `Один игрок` и откроет нужный реплей. Старый `Warcraft III.exe` не используется. Без iCCup Launcher обычные реплеи запускаются напрямую через `war3.exe`. Если автопоиск не сработал, нажми `Настроить запуск` и укажи iCCup `Launcher.exe` и связанный с ним `war3.exe` версии 1.26a. После загрузки нажми `Подключиться к Warcraft`. Точки позади текущего времени открываются через автоматический перезапуск реплея.

В направлении `Съёмка`: стрелки — полёт, Insert/Delete — поворот, Home/End — наклон, Page Up/Page Down — зум, Num 1/Num 0 — высота, Num 4/5/6 — повороты Drone. Назначь героев десяти слотам и выбери клавиши для камеры, Follow, Smart Follow, операторских шотов, сброса и каждого слота. Камера разделена на компактные вкладки управления, героев, шотов и Fly Drone. Макросы работают прямо в Warcraft без Alt-Tab. Во время Follow родная прокрутка у края экрана блокируется, а кнопка `Вернуть стандартный обзор` безопасно возвращает исходную камеру.
