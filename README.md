# Warcraft III Replay Lab

## Запуск

1. Установить Python 3.11 или новее.
2. Выполнить `python -m pip install -r requirements.txt`.
3. Запустить `START_REPLAY_LAB.cmd`.

## Работа с Warcraft

Выбери реплей и нажми `Открыть в Warcraft`. Если установлен iCCup Launcher, приложение само запустит Warcraft через его кнопку `Один игрок` и откроет нужный реплей. Старый `Warcraft III.exe` не используется. Без iCCup Launcher обычные реплеи запускаются напрямую через `war3.exe`. Если автопоиск не сработал, нажми `Настроить запуск` и укажи iCCup `Launcher.exe` и связанный с ним `war3.exe` версии 1.26a. Instant Seek подключится после загрузки автоматически и не запускает перемотку само по себе. Точки позади текущего времени открываются через автоматический перезапуск реплея. В `Skills HUD` список игроков выбирает героя; HUD выводит поверх Warcraft полную command card 3×4 с текущими уровнями и кулдаунами способностей выбранного героя. После подключения к реплею HUD запускается автоматически и следует за кликами в Warcraft; клавиши геройских слотов 1–0 сохраняют штатный переход observer mode и параллельно меняют родной портрет и HUD. Предметные и служебные способности не могут вытеснить записанные скиллы героя. Не-герои сохраняют последнюю валидную цель. У Invoker две активные способности восстанавливаются из записанных orb/Invoke действий на текущем времени реплея. Пассивная подсказка по наведению показывает название, уровень и кулдаун, не перехватывая мышь Warcraft. Skills HUD не зависит от Instant Seek или Camera Engine. Проверенный профиль даёт точные названия и иконки; на остальных картах HUD использует общий каталог и rawcode-плитки с реальными уровнями и кулдаунами.

В направлении `Съёмка`: стрелки — полёт, Insert/Delete — поворот, Home/End — наклон, Page Up/Page Down — зум, Num 1/Num 0 — высота, Num 4/5/6 — повороты Drone, Num 8/Num 2 — Orbit и смена направления, Num 7/Num 9 — соседняя окружность ближе или дальше. Назначь героев десяти слотам и выбери клавиши для камеры, Follow, Smart Follow, операторских шотов, сброса и каждого слота. Съёмка разделена на компактные вкладки управления, героев, шотов, Fly Drone/Orbit и Skills HUD. Кнопка `Настройки по умолчанию` возвращает стандартные параметры камеры, шотов, Drone/Orbit и клавиши, не меняя пути запуска и реплеи. Макросы работают прямо в Warcraft без Alt-Tab. Во время Follow родная прокрутка у края экрана блокируется, а кнопка `Вернуть стандартный обзор` безопасно возвращает исходную камеру.

Сборка предназначена для Windows 10/11 x64. Некритичные сообщения записываются в `%LOCALAPPDATA%\ReplayLab\logs\ReplayLab.log`.
