# Security policy

## Supported version

Security fixes are currently evaluated for the latest public stable release:

| Version | Supported |
|---|---|
| 0.5.1 | Yes |
| Older releases | No |
| Private development builds | Not publicly supported |

## Reporting a vulnerability

Do not disclose vulnerabilities, process-memory details, credentials or
sensitive diagnostic logs in a public issue.

Use GitHub's **Report a vulnerability** action on the repository Security page:

https://github.com/LivetARSmartA/ReplayLab/security/advisories/new

Include the ReplayLab version, Windows version, Warcraft build, reproduction
steps and the smallest relevant log excerpt. Replay files and complete logs may
contain player names or local filesystem paths; remove unrelated personal data
before attaching them.
